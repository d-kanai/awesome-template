## 🔧 主要な技術的決定事項

### 1. httpOnly Cookie認証
- **バックエンド**: signin/signupでSet-Cookie
- **フロントエンド**: `credentials: 'include'`
- **Cookie属性**: `httpOnly: true`, `secure: true`, `sameSite: 'lax'`
- **CSRF対策**: SameSite + トークン検証

### 2. Next.js Server Components + Client Components
- **Server Components**: レイアウト、静的コンテンツ
- **Client Components**: フォーム、状態管理（'use client'）

### 3. デザインシステム（Figma連携）
- **features/shared/figma_generated/**: Figmaから自動取り込み
  - Button, Input, Label, Card等の基本コンポーネント
  - Figma Code Connectで連携
  - .gitignoreで管理（自動生成のため）
- **features/shared/components/**: 自作コンポーネント
  - FormInput等、Figmaコンポーネントを組み合わせた独自コンポーネント
  - ビジネスロジック含むコンポーネント
- **class-variance-authority**: バリアント管理
- **CSS変数**: デザイントークン（Figmaと同期）

### 4. Playwright + Gherkin
- **@cucumber/cucumber**: feature files + step definitions
- **ブラウザ**: Chromiumのみ
- **構成**: e2e/features/*.feature, e2e/steps/*.steps.ts

### 5. テストファイル配置
- **実コードの横**: Component.tsx → Component.spec.tsx
- **Vitestパターン**: `**/*.spec.{ts,tsx}`
- **除外**: api/generated, figma_generated

### 6. AWS ECS デプロイ
- **Dockerfile**: マルチステージビルド、standalone出力
- **ベースイメージ**: node:22.11.0-alpine
- **ポート**: 3000
- **ヘルスチェック**: GET /api/health
- **環境変数**: NEXT_PUBLIC_API_BASE_URL

```
│ - SigninForm.tsx                         │
└─────────────────────────────────────────┘
```

### ディレクトリ構造の方針
1. **features/shared/figma_generated/**: Figmaが真実の源泉（SSOT）
   - 手動編集禁止
   - .gitignoreで除外推奨
   - Figma Code Connectで自動生成

2. **features/shared/components/**: 独自ビジネスロジック
   - figma_generatedを組み合わせて作成
   - 手動で実装・管理
   - Git管理対象

3. **各feature配下のcomponents/**: 機能特化コンポーネント
   - shared/componentsとfigma_generatedを使用
   - 機能固有のロジックを持つ

### 実装時の注意点
1. **Node.js**: 22.11.0（LTS）固定
2. **フォルダ名**: `users` → `user`
3. **テスト配置**: 実コードの横に`.spec`
4. **E2E**: Gherkin必須（.feature + .steps.ts）
5. **ブラウザ**: Chromiumのみ
6. **Figma生成**: figma_generated/は自動生成、手動編集禁止
7. **日本語**: テスト説明、given/when/thenコメント
8. **native参考**: 既存パターンを踏襲
9. **バージョン**: すべて固定（latestや^を使わない）
